操作方式

可以在遊戲選單的設定（頂部列最右側的按鈕）中選擇操作模式：

  • 休閒：在螢幕任何地方拖曳，雷恩會跟著您的手指移動，手指按住時持續射擊。點一下掉落的武器即可更換。
  • 玩家：在螢幕任何地方用搖桿移動，另一隻拇指按住「射擊」按鈕。「射擊」按鈕也可以放在左側，方便慣用左手的玩家。
  • 也支援遊戲控制器（Xbox、PlayStation、MFi）：搖桿或方向鍵移動，A 射擊，X 喝藥水，Y 丟炸彈，B 離開選單。
  • 也支援鍵盤：方向鍵或 WASD 移動，Space 射擊，Q 喝藥水，E 丟炸彈，Tab 開啟遊戲選單，Esc 離開選單。

在 iPhone 上，遊戲預設為休閒模式；在 iPad 或 Mac 上預設為玩家模式（在 Mac 上以鍵盤遊玩）。您可以隨時切換。

難度（簡單、普通或困難）可以隨時在設定中更改，並立即生效。

存檔與繼續

每當雷恩抵達一個村莊，以及您在村莊裡做了任何事情之後，遊戲都會自動存檔。在標題畫面選擇繼續，即可從最後抵達的村莊接著玩。道路上的進度不會在中途儲存，所以每條道路一律從頭開始。

您的旅程只儲存在這台裝置上。它不會透過 iCloud 同步到您的其他裝置，但會包含在裝置本身的備份中，因此將備份回復到新手機後，旅程也會一併轉移。刪除遊戲會同時刪除您的旅程。

雷恩倒下時

心耗盡後，您有十秒鐘決定是否繼續。點一下即可帶著全滿的心回到這條道路出發時所在的村莊，再試一次或改走別條道路。您會失去自這條道路開始以來找到的金幣。如果是在與守衛戰鬥時倒下，金幣會保留，繼續後將重新挑戰這場戰鬥。商店販售瓶子和護符，廚房可以把瓶子裝滿藥水並烹煮路上吃的料理，鐵匠鋪販售武器、盔甲和盾牌：它們都能在艱難的道路上助您一臂之力。

卡關了嗎？

和村民聊聊吧：他們會告訴您被擋住的路通往哪裡，以及需要什麼才能通過。他們說過的話都會記在遊戲選單的日誌裡。地圖會顯示您已經發現的道路。

購買

整個遊戲都可以免費遊玩直到破關。唯一的購買項目皮普的贊助人是選購的：它讓您成為吟遊詩人的贊助人，可以立即領取店主們的禮物而不必觀看廣告，傳送門免費，還能享受皮普的歌集和夢境。如果您已購買但沒有生效，請開啟設定，選擇皮普的贊助人，然後點一下恢復購買，並使用購買時的同一個 Apple 帳號。支援家人共享。

廣告

只有當您選擇觀看廣告，以便在商店、廚房或鐵匠鋪領取店主的禮物時，才會播放廣告。如果沒有提供禮物，表示廣告尚未準備好：請檢查網路連線，稍後再試。贊助人領取禮物完全不必觀看廣告。在要求廣告同意的地區，您可以在設定 → 廣告隱私中更改您的選擇。詳情請參閱隱私權政策。

Game Center

成就和連戰排行榜使用 Game Center。如果它們沒有顯示，請在裝置的「設定」（Mac 上為「系統設定」）中確認您已登入 Game Center，然後重新開啟遊戲。

語言

如果 Gravensmoor 支援您裝置的語言，就會使用該語言：英文、巴西葡萄牙文、西班牙文、德文、法文、義大利文、日文、韓文、簡體中文和繁體中文。您也可以在設定中選擇其他語言；遊戲會以該語言重新啟動，您的旅程將從上一個村莊繼續。
